# Blatmetro Secretary — Test Bot

Отдельная тестовая копия Telegram-бота. Исходная папка `BlatmetroSecretary_LocalAI`
и проект `BlatmetroSecretary_Training` в архиве сохранены без изменений.

## Что добавлено

- Подключение к Qwen2.5-0.5B-Instruct через llama.cpp.
- Настройка профиля `/setuser`: обращение, роль и стиль общения.
- `/myprofile` — просмотр своего профиля.
- `/resetprofile` — сброс своего профиля.
- `/reset` — очистка только своей истории.
- `/cancel` — отмена настройки профиля.
- Профили и история хранятся в `data/testbot.sqlite3` и разделены по Telegram user_id.
- Файл модели Qwen уже лежит в корне архива: `qwen2.5-0.5b-instruct-q4_k_m.gguf`. Он не дублируется, чтобы архив не занимал ещё примерно 470 MiB.

## Запуск

1. Распакуй архив.
2. Открой папку `BlatmetroSecretary_TestBot`.
3. Скопируй `.env.example` в `.env`.
4. В `.env` вставь токен отдельного тестового бота, созданного через @BotFather.
   Не используй токен основного бота и никому его не отправляй.
5. Убедись, что llama-server запущен на компьютере с моделью Qwen и слушает
   `127.0.0.1:9931`.
6. Запусти `run_bot.bat`.

Для текущей конфигурации Acer команда сервера:

```cmd
cd /d "C:\Users\Egor\Documents\Telegram bot\lama"
llama-server.exe -m "ПОЛНЫЙ_ПУТЬ_К_АРХИВУ\BlatmetroSecretary_TestBot\models\qwen2.5-0.5b-instruct-q4_k_m.gguf" --host 127.0.0.1 --port 9931 -c 2048 -t 2
```

Если сервер уже запущен с этой же моделью на порту 9931, повторно запускать его не нужно.

## Важно

- Это отдельный тестовый бот. Старый бот и тренировочные файлы не заменяются.
- В архиве нет Telegram-токена. Он должен оставаться только в локальном `.env`.
- SQLite-база создаётся автоматически при первом запуске.
- Не запускай одновременно две копии тестового бота с одним и тем же Telegram-токеном.
